# Pong

This is the first project hosted on my website. Pong represents one of the largest learning curves in my programming experience, second only to learning JavaScript for the first time.

## Learning Objectives

- Demonstrate general knowledge of the HTML5 canvas
- Construct a cohesive video game with a title screen, core gameplay loop, game over screen, and multiple game modes
- Develop a program that works consistently across all devices and hardware
- Introduce basic sound design through various sound effects
- Create an appropriate level of difficulty for the player

## Original Commentary (1/20/2022)

Being the first game I have completed, this game is not up to par in quality of many other HTML5 games on the internet. I mainly used this game to test my knowledge of the HTML5 Canvas, as development of this game began immediately after finishing a course on Youtube by the channel [Chris Courses](https://youtube.com/playlist?list=PLpPnRKq7eNW3We9VdCfx9fprhqXHwTPXL). Overall this game served as a necessary first step towards making future games. Even though this game is heavily lacking in visual and audio quality, I find the gameplay to be enjoyable, and thus I am happy with how the project turned out.

## Reflection (8/19/2026)

This was certainly an exciting and nerve wracking project to work on. This project's whole purpose was to solidify my knowledge of the HTML5 canvas. Learning to think in incremental frames was very difficult at first, but watching my code really come to life in animation was very rewarding. I don't have much else to say about this project. Looking back it was a very simple yet monumental step in my learning.
