Pong

This project is not available for mobile use. Please try again on a larger display

Completion Date: 1/20/22

Development Time: 3 Weeks

Being the first game I have completed, this game is not up to par in quality of many other HTML5 games on the internet. I mainly used this game to test my knowledge of the HTML5 Canvas, as development of this game began immediately after finishing a course on Youtube by the channel Chris Courses. Overall this game served as a necessary first step towards making future games. Even though this game is heavily lacking in visual and audio quality, I find the gameplay to be enjoyable, and thus I am happy with how the project turned out.
